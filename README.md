## Setup

### Install dependencies

```sh
npm install
```

### Start Development Server

```sh
npm run dev
```

### Building and Running for Production

1. Generate a production build

   ```sh
   npm run build
   ```

1. Preview the site

   ```sh
   npm run serve
   ```
